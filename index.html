About

This is a personal academic reading dashboard for HCRI76000.

It combines university-provided core and additional readings with wider readings drawn from response bibliographies.

Links are preserved exactly as supplied in the canonical readings.json data source.

This first version organises and links readings but does not host full PDF text, scrape sources, run OCR or fetch institutional links.
